# Tracewell: Privacy Policy

_Last updated: 10 November 2026_

Tracewell is an Atlassian Forge app that shows audit readiness and traceability for Jira projects.

## What data Tracewell processes
- **Jira and Confluence content you can already see.** This means issue summaries, statuses, labels, links, versions and change history. Tracewell reads it as the signed-in user in order to calculate readiness and to draw its screens. It is not copied out of Atlassian.
- **Confluence pages you ask it to create.** The audit dossier is written into a Confluence space that you choose.

## What data Tracewell stores
In Forge storage, which is hosted by Atlassian inside your site's Forge environment, Tracewell keeps only:
- project settings (the framework and label names you choose)
- one aggregated readiness snapshot per project per day (date, score and gap counts)
- the issue keys of the demo issues it created, so that you can remove them later

Tracewell does **not** store personal data such as account IDs, names or email addresses. It does not send any data to servers outside Atlassian, and it uses no analytics, cookies or trackers.

## AI features
The Rovo agent and the MCP tools return the same read-only data to Atlassian Rovo, or to the AI client you connect. Those tools always run with your own Jira permissions.

## Data retention and deletion
Uninstalling Tracewell deletes its Forge storage. Demo issues can be removed from the app's Settings tab.
