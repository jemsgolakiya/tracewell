## Rules for winning
1. **The demo must work for a stranger.** Judges install from your link onto *their* site, so the one-click demo is the most important feature. Test it on a fresh site at least twice.
2. **One story, told the same way everywhere:** *"Show me the verification evidence for SRS-114."* → BLOCKED → suspect link → fix → AT RISK → dossier.
3. **Show depth on screen.** Name the modules on the closing slide: projectPage, issuePanel, macro, rovo:agent, action, rovo:mcp, Teamwork Graph, KVS, scheduledTrigger.
4. **Don't overclaim.** Say "audit readiness", never "certified compliant". Regulated-industry judges will notice.
5. **Submit 2 days early.** Devpost and YouTube processing do fail on deadline day.
